## Бэклог

Не запланировано. Не перепроверено, если не сказано иное.

**Авторизация и безопасность**

- GitHub OAuth: зарегистрировать app в GitHub Settings, добавить стратегию `passport-github2` (сейчас её нет). Другие провайдеры (Discord, Apple и т.д.) по желанию
- Переключатель аккаунта Google при входе: сейчас при активной Google-сессии вход происходит молча без выбора аккаунта. Решение: `prompt: 'select_account'`, возможно как опция в настройках, а не жёстко
- Рейт-лимит на чувствительные эндпоинты (`@nestjs/throttler`: логин, refresh, поиск пользователей). Осознанная дыра: поиск пользователей даёт перебрать базу целиком, 36² запросов. Сейчас в API этого нет
- Идентификатор пользователя: username из части email не годится по соображениям конфиденциальности. Нужна схема уникального id, который пользователь сможет сам сменить (не перепроверено)
- Управление секретами: Doppler или Infisical, вместе с деплоем и CI/CD

**Интерфейс**

- Уведомления об исходе фоновых запросов (toast/snackbar): модалка книги закрывается сразу, ошибка сейчас просто гасится, успех не показывается. Системы уведомлений в проекте нет
- Баг: на мобильном выбранная тема не применяется на странице логина, пользователь в тёмной теме Ink видит зелёную (не перепроверено)
- Баг: двойное мерцание при закрытии модалки книги (#211), причина в spring-анимации Framer Motion
- Переименовать дефолтное отображаемое имя гостя, «мечтатель» не нравится (не перепроверено)
- Мобильная версия лендинга
- Доработки вкладки «Друзья»: запоминание активной вкладки профиля в query-параметре, чтобы «назад» с профиля друга возвращал в то же состояние; остаток выноса инлайн-`sx` в SCSS (`RatingPicker`, `GuestBanner`, `BookTableRow`, `BookCoverCardSkeleton`, `router.tsx`, `AuthCallbackPage`, `BooksCollection`)
- Раздел «Creators»: ссылки на соцсети пока заглушки (`url: '#'` в `CREATORS`), нужны реальные
- Загрузка и смена аватара (решить хранилище: S3 или локально), редактирование bio (поля ввода нет нигде), Zod для валидации ответов API, skeleton-экраны, расширенные фильтры библиотеки (ползунок минимального рейтинга), свайпы для смены вида

**Продукт**

- Библиотека переезжает в профиль: профиль = записи пользователя, `/library` = поиск книг по внешним API (Google Books или аналог). Шаги: вкладка «Библиотека» в своём профиле, затем `/library` превращается в поиск
- Таб «Полка» / «Выставка»: пользователь сам выбирает книги, которыми делится, остальные видят только эту подборку. Название не финализировано
- Real-time уведомления о заявках в друзья через тот же WebSocket-канал, а не отдельным механизмом
- Гостевой режим: данные в localStorage / IndexedDB с подсказкой, миграция при входе по кнопке (не автоматически), при конфликтах выбор «заменить / объединить / пропустить», экспорт и импорт JSON
- E2E-тесты (Playwright), PWA (offline, install prompt)
- Редактирование общей карточки книги (`handleSaveBook`) под вопросом: правка автора меняет его у всех, кто добавил ту же книгу. Не трогать без явного решения

## Идеи

- Календарь активности в статистике профиля: теплокарта по дням за год, как на GitHub. Для книг отметка «читал сегодня», опционально сколько страниц; для игр бинарная отметка, для фильмов и сериалов «посмотрел фильм / серию»
- Добавление активности вручную: перенос списка из блокнота с датами задним числом, у оценки пока нет своей даты
- Импорт списков из Goodreads и HLTB; события журнала должны создаваться с исходными датами, а не с датой импорта
- Игры, фильмы и сериалы как отдельные разделы
- Свой цвет обложки книги, поля «Тип» и «Год» у книги
- Блок «Продолжить чтение» на главной, двухколоночная модалка книги (обложка слева, остальное справа)
- Настройки одной длинной страницей с якорями, список изменений (changelog) на главной
- Аватары-животные в стиле приложения, цвет подстраивается под тему
